Field guide

How to use the laboratory

Choose a cipher, enter a message and a valid key, then Encrypt or Decrypt. Swap exchanges input and output. Sound starts only after you enable it. Interface buttons switch between three visual directions.

Key formats and text handling

Caesar: integer shift. Substitution: 26 unique letters. Playfair, Vigenère, Columnar: alphabetic keyword. Hill: four integers with invertible determinant. OTP: one key letter per message letter. Rail Fence: 2 or more rails, up to message length. Playfair and Hill normalize to uppercase letters; Playfair merges J into I and may add X/Q fillers. Hill pads odd messages with X. Other methods preserve punctuation and case; transposition rearranges all characters and uses no padding.

Security and limitations

These classical ciphers are for learning, not modern confidential communication. A true one-time pad requires a uniformly random secret key used once; the bundled example is educational. Playfair filler characters and Hill padding remain after decryption because removing them automatically can destroy genuine letters. History stores only operation metadata, never text or keys.
